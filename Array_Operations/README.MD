## Find the maximum element in an Array

#### Steps

##### Finding Max and min value in an Array

``` 
initialize an array with some integer values
now our goal is to find max or min value on array

first we will assume the first element as max or min then  compare it with other elements
if any element is greater than max or min then we will update the max or min value
finally we will print the max or min value
```

##### Finding sum of all the values in an array
```
initialize an array with some integer values
now our goal is to find sum of all the values in an array
first we will assume the sum as 0 then  we will add each element to sum
finally we will print the sum value
```

##### Finding the average of all the values in an array
```
initialize an array with some integer values
now our goal is to find average of all the values in an array
first we will assume the sum as 0 then  we will add each element to sum
then we will divide the sum by number of elements in an array to get average
finally we will print the average value
```

##### Finding the number od odd and even numbers in an array

```
initialize an array with some integer values
now our goal is to find number of odd and even numbers in an array
first we will assume the count of odd and even as 0 then  we will check each
element if it is divisible by 2 then it is even otherwise odd
then we will increment the count of odd or even accordingly
finally we will print the count of odd and even numbers
```

##### Finding the second largest element in an array
```
initialize an array with some integer values
now our goal is to find second largest element in an array
first we will assume the first element as largest and second largest
then we will compare each element with largest and second largest
if any element is greater than largest then we will update second largest as largest and largest as element
if any element is greater than second largest and less than largest then we will update second largest as element
finally we will print the second largest value
```
